- 晚辅、班课各自创建班级，班级数据彼此独立，学生能进入对应个人页面。
- 从 Excel 格式文本批量粘贴，空白年级采用班级默认值。
- 预览识别重复行与缺失姓名行；默认仅勾选有效且不重复的行，确认后数量正确。

- 下载 CSV 模板，再通过文件选择器读取，中文与各字段解析正确。
- 编辑班级时间并保存；删除确认展示关联学生数量，取消保留数据，确认只删除目标班级及其学生。
