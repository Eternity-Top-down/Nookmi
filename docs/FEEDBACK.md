# 课程反馈使用说明

适用版本：v0.2.0。本版先让每次课的反馈能够填写、保存、修改和复制。正文使用自由文本，暂不设置固定评价项目或模板。

## 一对一：进入学生就开始写

1. 在「一对一」中点击学生，默认打开课程反馈页面。
2. 设置本次上课时间，填写反馈正文。
3. 保存后，这次课的反馈进入历史列表。需要调整时，打开对应历史反馈修改并再次保存。
4. 使用复制功能，将反馈粘贴到日常沟通工具中，再由自己核对并发送。

需要补充学生资料或查看此前的教学记录时，切换到「学生档案与笔记」。原有学情备注与教学记录仍然保留，课程反馈单独保存。

## 晚辅与班课：在同一名单中完成反馈

1. 进入目标班级，默认打开班级反馈页面。
2. 设置这次课的时间，在名单中分别填写每位学生的反馈。
3. 不必等全班写完才保存。先保存已完成的部分，页面会显示完成数量。
4. 后续从历史记录打开这次课，继续补写或修改。
5. 可以逐人复制，也可以复制全班已填写的反馈。空白学生不会出现在复制结果中。

新增或维护学生时，切换「学生管理」，可以单独录入、批量粘贴名单，再点击学生查看资料。

## 保存与复制

- 点击保存后，反馈才进入当前浏览器的数据存储。复制内容不等于保存。
- 有未保存内容时，离开反馈工作区会提醒；需要保留修改时，先取消离开并保存。
- 如果浏览器无法直接写入剪贴板，界面会提供可手动选择复制的文本。
- 复制只准备好文字，不会向家长或其他人自动发送消息。

## 更新后的数据

v0.2.0 继续使用原有浏览器保存位置，旧的学生、班级和教学记录无需重新录入。更新程序后，刷新此前使用的同一浏览器地址即可查看反馈入口。

导出的备份包含已保存反馈。恢复旧版备份仍受支持，但恢复是整体替换，旧备份里没有的反馈不会自动合并保留。恢复前先导出当前备份。

本版仍没有 SQLite、服务端存储或跨设备同步。不同设备、浏览器、域名和端口之间的数据不会自动共享。
