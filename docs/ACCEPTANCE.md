# v0.5.0 手动验收清单

本清单用于验证实际操作流程。下列勾选框是待执行检查项，不表示检查已经通过。请使用虚构学生信息进行测试。

准备：执行 `npm ci`、`npm run setup:backend` 和 `npm run start`。测试时通过 `NOOKMI_DATA_DIR` 指定独立数据库；仅更换浏览器或前端端口不会隔离同一后端的数据。当前已执行结果见 [验证记录](VERIFICATION.md)。

## AI、原始观察与持久化

- [ ] 晚辅与班课的共用教学内容写一次，切换学生时保持；每位学生的观察与正文相互独立。
- [ ] 主输入框允许混写真实表现、亮点、困难和建议，不要求逐项填写；「补充细节」默认按需展开。
- [ ] 旧记录的亮点、困难或建议已有内容时，选填区域自动展开，原文字保留且可继续编辑。
- [ ] 一对一按课程时间、晚辅默认周一至周五、班课默认当月起止，均可修改。
- [ ] 晚辅初二、初三分别默认数物、数物化；删除某科后已有该科记录仍可查看处理。
- [ ] 仅有建议或任务时可以保存，但没有个人事实不能调用 AI 生成。
- [ ] 未配置服务时给出明确提示，输入保留；原始整理标为非 AI。
- [ ] 保存并测试服务连接成功；再次打开设置不显示已保存密钥。
- [ ] 批量跳过无事实或已有正文的学生，失败与成功相互隔离，可重试剩余学生。
- [ ] 已有正文重新生成时先比较候选，保留原文和接受替换均正确。
- [ ] 生成期间修改事实或正文，旧响应不能覆盖；停止生成后也不能写入。
- [ ] 生成期间离开得到提醒；取消离开仍保留输入。
- [ ] 修改原始观察或正文后取消核对状态，重新核对才可复制。
- [ ] 保存失败或版本冲突保留输入，不能误报成功。
- [ ] 关闭并重启 Python 后端，数据库中的草稿和原始观察仍存在。
- [ ] 空数据库可迁移旧版资料，浏览器旧副本保留；有数据时不自动覆盖。
- [ ] 从两个页面修改同一数据，后提交的过期版本被拒绝。
- [ ] 备份含共用内容、个人观察、正文、核对状态与模块风格参考，不含 AI 设置或密钥。

## 本机草稿、自动保存与冲突

- [ ] 输入课程内容、观察或正文后立即刷新，同一浏览器同一地址下可恢复，不要求先点保存。
- [ ] 有效且非空的反馈停笔约 1 秒自动保存到 SQLite，状态由等待保存变为已保存到数据库。
- [ ] 持续输入期间不重复提交；保存期间继续输入，新文字不被旧响应覆盖或从本机草稿中删除。
- [ ] 暂时清空日期、输入反向周期或不完整学科时，本机草稿保留；修正后自动保存。
- [ ] 后端离线时输入保留且显示未同步，普通保存失败在页面开启时约 15 秒重试，后端恢复后可同步。
- [ ] 不同学生、班级、模块与历史反馈的本机草稿分别恢复，不串用内容。
- [ ] 已暂存反馈切换页面后仍可回到原记录继续；生成中或本机暂存失败时离开有提示。
- [ ] 两个页面出现版本冲突时暂停自动保存，不重复覆盖；重新读取后本机文字仍可处理。
- [ ] 恢复草稿与数据库基准不同，展示冲突；另存为新反馈保留本机文字且不覆盖原数据库记录。
- [ ] 明确采用数据库版本才放弃冲突草稿；取消确认仍保留本机内容。
- [ ] `localhost`、`127.0.0.1`、不同端口或不同浏览器不共享本机草稿；同一后端的正式 SQLite 数据仍可共用。
- [ ] 浏览器存储被拒绝或写满时明确提示，内存文字保留，不错误显示可靠暂存；可先复制留存。
- [ ] 备份只包含数据库已保存内容；无效日期草稿及未同步文字不误入正式备份。
- [ ] 三模块界面不再显示 AI 推荐记录、获取推荐或加入推荐按钮；完整反馈生成仍可用。

## 个人风格参考

- [ ] 三模块反馈页面均能展开「个人风格参考」，显示对应模块名称与设置状态。
- [ ] 分别保存三份不同参考，切换模块后不会串用；同模块其他学生或班级使用同一份参考。
- [ ] 编辑时同步本机暂存，刷新恢复并展开；未点击保存时数据库和 AI 仍使用原参考。
- [ ] 手动保存后刷新页面及重启后端仍保留参考，数据库与导出备份中的 `feedbackStyles` 正确。
- [ ] 「撤销修改」恢复已保存内容；有外部新值时恢复最新内容。清空并保存可移除参考。
- [ ] 未保存风格时 AI 正文生成按钮不可用；保存或撤销后恢复，离开页面时提醒。
- [ ] 保存失败保留风格输入；反馈与风格同时保存时，未成功的一方仍可重试，已保存内容不丢失。
- [ ] 参考更新不会静默覆盖本地未保存的参考输入；可以明确选择加载最新参考。
- [ ] 正文生成请求带上当前模块已保存的 `styleReference`；未设置风格也能正常请求。
- [ ] 修改风格后，旧 AI 响应和候选不能覆盖当前内容，已有正文保持可查看、编辑。
- [ ] 参考最多 12000 字，超限备份或 API 写入被拒绝；界面有字数及去除身份信息的提示。
- [ ] 本机范文与数据库最新参考冲突时保留输入，可明确加载最新参考；不会在后台自动覆盖。
- [ ] 清空但未保存的范文也能刷新恢复；成功保存、明确撤销或加载最新参考后清理对应缓存。
- [ ] 风格暂存失败或清除失败均提示；一个模块失败不会静默误报全部清除，也不清理其他应用数据。

## 一对一课程反馈

- [ ] 点击一对一学生后，默认进入课程反馈页面。
- [ ] 一对一只有一个「课后任务」输入，不出现共用任务或个人任务的重复输入；晚辅与班课仍各有共用和个人任务。
- [ ] 旧一对一记录的共用任务与个人任务完整合并显示，保存刷新后不丢失；旧已写正文保持不变。
- [ ] 一对一课后任务最多 8000 字；旧 5000 字共用任务和 2000 字个人任务合并后仍能编辑保存。
- [ ] 填写上课时间和自由文本反馈，保存后出现在历史列表中。
- [ ] 刷新同一地址后，已保存的反馈仍然存在，时间与正文正确。
- [ ] 打开历史反馈进行修改，保存后更新原反馈，不新增重复记录。
- [ ] 新建另一节课的反馈后，前一节课的内容仍保留。
- [ ] 复制当前反馈，粘贴到文本编辑器后核对学生、时间和正文。
- [ ] 无正文但有原始观察或课程内容可自动存入数据库；完全空白或无效时间仅保留本机草稿。
- [ ] 切换学生、模块、页面或历史反馈后，本机未同步内容仍可恢复；出现风险提示时取消不会丢字。
- [ ] 切换到「学生档案与笔记」后，可以查看、修改原有学生信息和教学记录。

## 晚辅与班课反馈

- [ ] 进入晚辅或班课的班级后，默认进入班级反馈页面。
- [ ] 「学生管理」中保留单独新增、批量录入、查看和维护学生的入口。
- [ ] 设置本周或本月起止日期，在名单中为不同学生填写不同的反馈。
- [ ] 只填写一部分学生也能保存，完成数量与非空反馈数量一致。
- [ ] 从历史列表重新打开本次反馈，可以补写其余学生，已写内容保留。
- [ ] 编辑历史反馈并保存后更新同一次课程，不产生重复课程。
- [ ] 逐人复制只包含目标学生的已核对反馈；全班复制仅包含非空且已核对的反馈。
- [ ] 复制内容中的学生姓名与各自反馈对应，无串行或串班问题。
- [ ] 空班级提示先添加学生，可通过学生管理录入后进入班级反馈。
- [ ] 班级反馈与一对一反馈、其他班级反馈互不混淆。
- [ ] 离开班级反馈后可恢复本机未同步文字；生成中或暂存失败时出现提示，取消后正文保留。

## 反馈复制与兼容

- [ ] 正常浏览器权限下可以直接复制反馈。
- [ ] 浏览器拒绝剪贴板访问时，出现可选中的文本，能够手动复制。
- [ ] 复制不会自动发送消息，也不会将未保存修改误报为已保存。
- [ ] 迁移 v0.1.0 数据后，旧学生、班级、教学记录正常显示。
- [ ] 导出并恢复 v0.5.0 备份后，周期、原始观察、正文、关联学生与三个模块的风格参考保持一致。
- [ ] 旧 v0.2.0 至 v0.4.1 备份可恢复；缺少 `feedbackStyles` 时显示未设置，不沿用恢复前的风格。
- [ ] 恢复 v0.1.0 备份可以成功；确认界面明确说明替换当前数据。
- [ ] 格式错误或学生、班级关联无效的反馈备份被拒绝，原有数据不受影响。
- [ ] 删除学生或班级后，不保留指向已删除对象的无效反馈关联。

## 一对一

- [ ] 新增学生，只填写姓名即可保存。
- [ ] 空姓名或纯空格姓名不能保存，并出现明确提示。
- [ ] 填写年级、学校、家长、联系电话和备注，保存后可在个人页面正确查看。
- [ ] 点击学生可进入对应个人页面，返回后仍处于一对一模块。
- [ ] 修改学生信息后，列表与个人页面同步更新。
- [ ] 搜索和年级筛选返回匹配结果，无匹配结果时显示清晰的空状态。
- [ ] 添加带日期的教学记录，刷新后仍能查看。
- [ ] 删除教学记录后，其余记录保持完整。
- [ ] 学生列表有删除快捷入口，点击不误入学生页面；只出现一次删除确认，明确列出影响。
- [ ] 取消删除不改变数据；确认后目标学生及关联记录被移除，其他学生保留。

## 晚辅与班课

- [ ] 分别在晚辅、班课创建班级，两个模块的班级互不混淆。
- [ ] 班级名称为空时无法保存。
- [ ] 编辑班级名称、年级、上课时间与备注，重新进入后信息正确。
- [ ] 在班级中新增学生，点击进入正确学生的个人页面。
- [ ] 从个人页面返回，仍处于原班级。
- [ ] 在不同班级中录入同名学生，能够分别进入各自的个人页面。
- [ ] 晚辅和班课的学生列表也可快捷删除，使用同样的一次确认流程。
- [ ] 删除班级前展示数据影响并要求确认；取消时班级和学生保留。
- [ ] 确认删除班级后，仅移除该班级及其关联学生、教学记录，其他班级不受影响。

## 批量录入

- [ ] 从 Excel / WPS 复制带表头的名单，粘贴后能正确识别字段。
- [ ] 复制不带表头的名单，按姓名、年级、学校、家长、联系电话、备注的顺序识别。
- [ ] 每行一个姓名也可以录入。
- [ ] 空白行不会产生空学生。
- [ ] 导入 UTF-8 CSV 文件，中文显示正确。
- [ ] CSV 中带引号、英文逗号或换行的备注保持完整。
- [ ] 缺失姓名、异常 CSV、过多列或超长字段在预览中提示，不能静默导入错误数据。
- [ ] 班级中已存在或当前名单中重复的学生得到提示，可以核对后选择要录入的行。
- [ ] 确认前的预览操作不改变现有学生列表。
- [ ] 确认后导入数量与所选有效记录一致，学生进入当前班级和模块。
- [ ] 取消批量录入不产生任何学生数据。

## 保存、备份与恢复

- [ ] 刷新页面后，学生、班级及教学记录仍然存在。
- [ ] 关闭页面后重新打开，连接同一后端可以读取已保存数据。
- [ ] 导出 JSON 备份，文件内容包含当前学生、班级、教学记录、反馈与已保存的模块风格参考。
- [ ] 恢复有效备份时明确提示替换现有数据；取消不改变任何记录。
- [ ] 确认恢复后，所有关联关系、字段及教学记录与备份一致。
- [ ] 恢复备份或清空数据库成功后，本机反馈与三个模块风格草稿被清理，刷新不复活旧输入。
- [ ] 取消、校验失败或后端保存失败时不清理本机草稿；浏览器清理失败时显示提示。
- [ ] 格式损坏、版本不兼容或关联关系错误的备份被拒绝，原数据保留。
- [ ] 后端停止或数据库无法写入时，保存失败有提示，当前输入保留，不出现虚假的保存成功。
- [ ] 空工作台可以载入虚构示例，已有真实工作数据时不会自动混入示例。

## 界面与构建

- [ ] 桌面窗口中，导航、列表、个人页面和弹窗布局完整。
- [ ] 手机尺寸下可以切换模块、创建班级、录入学生并查看个人页面。
- [ ] 仅使用键盘也可以操作主要按钮、填写表单、关闭弹窗。
- [ ] 弹窗标题、表单标签和错误提示清晰可见。
- [ ] 执行 `npm test` 成功。
- [ ] 执行 `npm run build` 成功。
- [ ] 执行后端 `python -m unittest discover -s backend/tests -v` 成功。
- [ ] 启动后端并执行 `npm run preview` 后，构建版本可以打开并完成基本操作。
